Entry for the make.fun bounty **Name the Robot Band** — one funny name for a
band made of robots, plus a few words on its hit song, all under 200 characters.

Run `node entry/main.ts`; it writes the single line to `/output/entry.txt`,
asserting the 1–200 character gate first and verifying the file by reading it back.

> N*SYNC — hit single 'Bye Bye Bye' ends every show when all five power down in perfect sync.
